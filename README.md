# Express API

API REST développée avec Node.js et Express.js.

## Objectifs

Projet d'apprentissage permettant d'expérimenter :

- Express.js
- API REST
- middlewares
- gestion des erreurs
- PostgreSQL
- Sequelize
- authentification
- gestion des sessions
- rôles métier
- déploiement

## Installation

npm install

## Développement

npm run dev

## Production

npm start

## Endpoints

GET /              Page d'accueil
GET /api/health    État de l'API
